# odoo-rpc-to-json-2

Este módulo para Odoo (versiones 16, 17 y 18) actúa como un "traductor" o capa de compatibilidad que implementa de forma anticipada el nuevo protocolo **JSON-RPC 2.0** que introduce Odoo 19.

### 🚀 ¿Por qué existe este repositorio?
Con la llegada de Odoo 19, el soporte para el clásico `xml-rpc` empieza a quedar en el pasado en favor de un estándar más moderno, rápido y seguro basado en JSON. 

Este addon está diseñado específicamente para desarrolladores que:
* Tienen integraciones heredadas (*legacy*) basadas en XML-RPC.
* Quieren facilitar la migración de sus sistemas externos hacia el nuevo estándar.
* Desean empezar a interactuar con Odoo 16-18 usando la estructura de datos que requerirá la versión 19.

### 🛠️ Versiones Soportadas
* Odoo 16.0
* Odoo 17.0
* Odoo 18.0
