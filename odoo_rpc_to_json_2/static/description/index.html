Capa de Compatibilidad JSON/2 API (Odoo 19)

Prepara tu infraestructura Odoo 16, 17 o 18 para el futuro estándar de integración externa de Odoo 19.

✓ Odoo 16 Soportado ✓ Odoo 17 Soportado ✓ Odoo 18 Soportado

Con la llegada de Odoo 19, el clásico protocolo XML-RPC es formalmente sustituido por la interfaz JSON/2 API, un estándar moderno, ágil y altamente optimizado. Este módulo de grado industrial actúa como un puente directo, permitiendo que tu Odoo actual exponga exactamente los mismos endpoints modernos (/json/2/...) y el protocolo envolvente legado (/jsonrpc2).

¿Por qué elegir este módulo?

🛡️

Seguridad Máxima (HMAC)

Validación de claves Bearer con protección anti-ataques de tiempo (Timing-Safe) a través de un bucle de comparación $O(N)$ constante sin escapes tempranos. Las claves se hashean en SHA-256.

🔌

Doble Endpoint Soportado

Expone la interfaz moderna REST /json/2/<model>/<method> y el protocolo envelope clásico /jsonrpc2 para compatibilidad absoluta con integradores web, scripts ERP y más.

📝

Logs y Auditoría

Visor integrado de logs en la UI de Odoo que registra IP de origen, usuario, duración exacta en milisegundos, estado de respuesta y trazas de error completas para depurar integraciones con facilidad.

Gestión Centralizada de API Keys

Los administradores pueden gestionar de forma unificada las claves de acceso de los sistemas externos. Asocia cada llave a un usuario específico del ERP para heredar sus reglas de control de acceso y ACLs nativas. También permite fijar fechas límites de expiración automáticas para maximizar la seguridad operativa.

  • Control administrativo absoluto sobre los accesos externos.
  • Estado visual en tiempo real (Archivado/Activo).
  • Herencia transparente de las reglas ACL del usuario seleccionado.

Asistente Emergente de Generación Segura

Gracias al nuevo menú dedicado y exclusivo de generación, los administradores pueden invocar un asistente emergente (wizard) rápido y limpio. Este flujo resuelve de raíz el problema de accesibilidad de Odoo cuando la base de datos de claves está vacía, guiándote paso a paso en la creación y mostrándote la clave completa para su copiado inmediato.

  • Acceso directo sin importar el estado de la vista lista.
  • Visualización completa y limpia de la clave generada.
  • Prevención de errores de copiado antes de almacenar el hash.

Monitorización de Logs y Depuración Rápida

¿Problemas de sincronización con tu tienda Shopify, Amazon o conector externo? La pestaña de API Logs es el aliado definitivo de los desarrolladores. Registra cada llamada entrante al servidor con precisión de milisegundos, indicando si falló la validación, si hubo errores de permisos (Access Error) o fallos de validación del ORM de Odoo.

  • Registro de dirección IP del cliente externo.
  • Duración del procesamiento en milisegundos.
  • Traceback de depuración visible si el servidor está en modo desarrollador.

¿Listo para conectar tu Odoo?

Simplemente instala el módulo, crea tu primera clave de API, y empieza a emitir peticiones seguras apuntando a /json/2/ tal y como lo exige Odoo 19. Ofrecemos compatibilidad retroactiva completa sin comprometer la seguridad ni el rendimiento.
