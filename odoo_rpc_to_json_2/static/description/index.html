JSON/2 API & JSON-RPC 2.0

Odoo 19 API Compatibility Layer for Odoo 16, 17 and 18

Expose Odoo 19 native endpoints /json/2/<model>/<method> and /jsonrpc2 in your current Odoo instance. Secure Bearer token authentication, IP whitelisting, rate limiting, and OpenAPI/Postman exports.

Odoo 16 / 17 / 18 Community & Enterprise SHA-256 Token Auth Zero Dependencies

Key Capabilities

Clean architecture, granular security, predictable authentication, and developer tooling.

⚡

Odoo 19 REST Interface

Direct mapping to ORM methods via /json/2/<model>/<method>. Returns standard JSON with semantic HTTP status codes (200, 400, 401, 403, 429, 500).

🔒

Granular Security & IP Whitelist

Restrict keys to specific models, methods, or IP/CIDR subnets (10.0.0.0/24). Timing-safe SHA-256 validation with fast index lookup.

⏱

Rate Limiting & Log Cleanup

Configurable request throttling (per minute/hour/day). Automated daily scheduled cron job for purging old API audit logs according to retention policies.

🛠

CORS, OpenAPI & Postman

Full CORS & OPTIONS preflight for SPAs. Includes ready-to-import OpenAPI 3.0 (/openapi.json) and Postman (/postman_collection.json) exports.

Access Control

API Key Management

Create and manage API keys tied to specific Odoo users. Each key inherits user ACLs and can be further restricted with granular model, method, IP whitelisting, and rate limits.

  • User-bound permissions with native Odoo security enforcement.
  • Model and method restrictions (Principle of Least Privilege).
  • IP whitelist and CIDR subnet restrictions.
  • Individual Active / Inactive toggle for immediate revocation.
Key Generation

Secure Key Creation Wizard

The built-in wizard generates a cryptographically random token with the jrpc2_ prefix. The raw token is displayed once and never stored in plain text.

  • One-time display of the plain token (not stored in cleartext).
  • SHA-256 hashing applied immediately upon storage with fast index lookup.
  • Optional model/method/IP restrictions and rate limit configuration.
Monitoring

API Request Logs

Monitor API activity and troubleshoot integration issues directly in Odoo without accessing server logs.

  • Tracks response duration (ms) to detect slow operations.
  • Records caller IP addresses and HTTP status codes.
  • Stores Python tracebacks for failed requests (debug mode).
  • Automatic log purging with scheduled cron cleanup.

Code Examples

REST endpoint and JSON-RPC 2.0 envelope examples.

cURL - POST /json/2/<model>/<method> 
# Search partners
curl -X POST https://your-odoo.com/json/2/res.partner/search_read \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer jrpc2_your_api_key" \
  -H "X-Odoo-Database: your_db" \
  -d '{"domain": [["is_company","=",true]], "fields": ["name","email"], "limit": 5}'

# Create a partner
curl -X POST https://your-odoo.com/json/2/res.partner/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer jrpc2_your_api_key" \
  -H "X-Odoo-Database: your_db" \
  -d '{"name": "Integration Corp", "email": "api@example.com"}'
Python (requests) 
import requests

url = "https://your-odoo.com/json/2/res.partner/search_read"
headers = {
    "Authorization": "Bearer jrpc2_your_api_key",
    "X-Odoo-Database": "your_db",
    "Content-Type": "application/json"
}
payload = {
    "domain": [["customer_rank", ">", 0]],
    "fields": ["id", "name", "email"],
    "limit": 10
}

response = requests.post(url, json=payload, headers=headers)
print("Status:", response.status_code)
print("Data:", response.json())
JSON-RPC 2.0 - POST /jsonrpc2 
curl -X POST https://your-odoo.com/jsonrpc2 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer jrpc2_your_api_key" \
  -d '{
    "jsonrpc": "2.0",
    "method": "call",
    "id": 1,
    "params": {
      "db": "your_db",
      "model": "res.partner",
      "method": "search_read",
      "args": [[]],
      "kwargs": {"fields": ["name"], "limit": 5}
    }
  }'

Error Response Format (e.g. 403)

{
  "name": "odoo.exceptions.AccessError",
  "message": "You do not have permission to access this document.",
  "debug": "(traceback - only in Odoo debug mode)"
}

Quick Setup

4 steps to get started.

1

Install

Place the module in your addons path and install from the Apps menu.
2

Create Key

Go to JSON-RPC 2.0 > Generate API Key. Pick a user and configure restrictions.
3

Send Request

POST to /json/2/model/method with Authorization: Bearer header.
4

Monitor

Check JSON-RPC 2.0 > API Logs for response times, status codes, and traces.
