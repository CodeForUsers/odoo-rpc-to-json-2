JSON/2 API Compatibility Layer (Odoo 19)

Prepare your Odoo 16, 17, or 18 infrastructure for the future Odoo 19 external integration standard.

✓ Odoo 16 Supported ✓ Odoo 17 Supported ✓ Odoo 18 Supported

With the arrival of Odoo 19, the classic XML-RPC protocol is formally replaced by the modern, agile, and highly optimized JSON/2 API interface. This industrial-grade module acts as a direct bridge, enabling your current Odoo instance to expose the exact same modern endpoints (/json/2/...) and the legacy wrapping protocol (/jsonrpc2).

Why choose this module?

🛡️

Maximum Security (HMAC)

Bearer key validation with constant-time ($O(N)$) timing-safe comparison protection and no short-circuiting. API keys are safely hashed using SHA-256.

🔌

Dual Endpoint Support

Exposes the modern RESTful /json/2/<model>/<method> interface and the classic /jsonrpc2 envelope protocol for absolute compatibility with web integrators, ERP scripts, and more.

📝

Logs & Auditing

Built-in logs viewer in the Odoo UI that records source IP, user, exact duration in milliseconds, response status, and full error tracebacks to debug integrations with ease.

Centralized API Key Management

Administrators can manage access keys for external systems in a unified panel. Associate each key with a specific ERP user to inherit their access control rules and native ACLs. It also allows setting automatic expiration dates to maximize operational security.

  • Absolute administrative control over external access.
  • Real-time visual status (Archived/Active).
  • Transparent inheritance of the selected user's ACL rules.

Secure Generation Pop-up Wizard

Thanks to the new dedicated and exclusive generation menu, administrators can trigger a clean and fast pop-up wizard. This workflow solves Odoo's accessibility issue when the keys list is empty, guiding you step-by-step through creation and showing the complete key for immediate copying.

  • Direct access regardless of the list view state.
  • Clean, complete display of the generated key.
  • Prevents copying errors before storing the hash.

Log Monitoring & Fast Debugging

Synchronization issues with your Shopify store, Amazon, or external connectors? The API Logs tab is the ultimate developer ally. It records every incoming server call with millisecond precision, indicating if validation failed, if there were permission errors (Access Error), or Odoo ORM validation issues.

  • Records the client IP address of external systems.
  • Processing duration tracked in milliseconds.
  • Debug traceback visible when the server is in developer mode.

Ready to connect your Odoo?

Simply install the module, create your first API key, and start making secure requests pointing to /json/2/ exactly as Odoo 19 requires. We offer full backward compatibility without compromising security or performance.
