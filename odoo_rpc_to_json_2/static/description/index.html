JSON/2 API & JSON-RPC 2.0

Odoo 19 API Compatibility Layer for Odoo 16, 17, and 18

Expose native /json/2/<model>/<method> and /jsonrpc2 endpoints in your Odoo instance. Build modern integrations with Bearer token authentication and ensure future compatibility without waiting for version upgrades.

✓ Odoo 16 / 17 / 18 ✓ Community & Enterprise ✓ Bearer Token Auth (SHA-256) ✓ Zero External Dependencies

Key Capabilities

Designed for clean architecture, predictable authentication, and easy maintenance.

⚡

Odoo 19 REST Interface (/json/2/)

Direct mapping to ORM methods via /json/2/<model>/<method>. Returns standard JSON and semantic HTTP status codes (200, 400, 401, 403, 404, 500).

🔒

Secure Token Authentication

API keys are stored as SHA-256 hashes and evaluated using constant-time comparison (hmac.compare_digest). Supports optional token expiration dates.

📋

Request Logging & Audit Trail

Automatic record of each incoming request: timestamp, client IP, authenticated user, endpoint, response status, execution duration in milliseconds, and error traces.

🔁

Dual Protocol Engine

Supports both the REST-style /json/2/ and the legacy JSON-RPC 2.0 envelope (/jsonrpc2), allowing smooth integration with various clients.

Access Control

API Key Management

Create and manage API keys tied to specific Odoo users. Each key strictly inherits the standard security groups, access control lists (ACLs), and record rules configured for that user in Odoo.

  • User-bound permissions with native Odoo security enforcement.
  • Individual Active / Inactive status toggle for immediate revocation.
  • Optional expiration dates for temporary access keys.
Key Generation

Fast & Secure Key Creation Wizard

The built-in wizard generates a cryptographically random token with the jrpc2_ prefix. The raw token is shown once during creation and is never stored in plain text in the database.

  • One-time display ensures the plain token is not stored in cleartext.
  • SHA-256 hashing applied immediately upon storage.
  • Simple modal workflow accessible from the technical menu.
Monitoring & Debugging

Detailed API Request Logs

Monitor incoming API activity and troubleshoot integration issues directly in Odoo without accessing server files or terminal logs.

  • Tracks response duration (ms) to detect slow ORM operations.
  • Records caller IP addresses and HTTP status codes.
  • Stores complete Python tracebacks for failed requests (in debug mode).

Protocol Comparison

Understanding how JSON/2 API compares with legacy integration methods.

Feature XML-RPC (Legacy) JSON-RPC 2.0 (/jsonrpc2) JSON/2 API (/json/2/)
Odoo 19 Compatibility ✗ Deprecated in Odoo 19 ⚙ Supported (envelope) ✓ Native Odoo 19 format
Authentication User credentials per call Bearer token in payload/header HTTP Authorization: Bearer
HTTP Status Codes Always 200 (XML fault on error) Always 200 (JSON error object) Semantic (200, 400, 401, 403, 500)
Payload Format Verbose XML JSON-RPC wrapper Clean JSON key-values
Tooling & HTTP Clients Requires XML-RPC library cURL, Postman, custom scripts Standard REST (Postman, cURL, Fetch)

Code Examples & API Usage

Examples for calling the REST-style endpoint and the JSON-RPC 2.0 envelope.

REST Endpoint — POST /json/2/<model>/<method> (cURL) Bash 
# 1. Search partners (search_read)
curl -X POST https://your-odoo-domain.com/json/2/res.partner/search_read \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer jrpc2_your_api_key_here" \
  -H "X-Odoo-Database: your_database_name" \
  -d '{"domain": [["is_company","=",true]], "fields": ["name", "email", "phone"], "limit": 5}'

# 2. Create a new partner (create)
curl -X POST https://your-odoo-domain.com/json/2/res.partner/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer jrpc2_your_api_key_here" \
  -H "X-Odoo-Database: your_database_name" \
  -d '{"name": "External Integration Corp", "email": "contact@integration.com"}'
Python (requests library) Python 
import requests

url = "https://your-odoo-domain.com/json/2/res.partner/search_read"
headers = {
    "Authorization": "Bearer jrpc2_your_api_key_here",
    "X-Odoo-Database": "your_database_name",
    "Content-Type": "application/json"
}
payload = {
    "domain": [["customer_rank", ">", 0]],
    "fields": ["id", "name", "email"],
    "limit": 10
}

response = requests.post(url, json=payload, headers=headers)
data = response.json()
print("Status:", response.status_code)
print("Partners:", data)
Classic JSON-RPC 2.0 (/jsonrpc2) 
curl -X POST https://your-odoo.com/jsonrpc2 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer jrpc2_key" \
  -d '{
    "jsonrpc": "2.0",
    "method": "call",
    "id": 1,
    "params": {
      "db": "your_db",
      "model": "res.partner",
      "method": "search_read",
      "args": [[]],
      "kwargs": {"fields": ["name"], "limit": 5}
    }
  }'
Standard Error Format (e.g. 403 Forbidden) 
{
  "name": "odoo.exceptions.AccessError",
  "message": "You do not have permission to access this document.",
  "debug": "<traceback only when in Odoo debug mode>"
}

Quick Setup

Get up and running in 4 straightforward steps.

1

Install Module

Place the module in your custom addons path and install it from the Apps menu.

2

Create API Key

Go to JSON-RPC 2.0 › Generate API Key, pick a user, and copy your token.

3

Send Requests

Make HTTP POST calls to /json/2/<model>/<method> with the Bearer header.

4

Monitor Logs

View response times, status codes, and tracebacks in JSON-RPC 2.0 › API Logs.
